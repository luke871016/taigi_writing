          功能介紹

          • 佇「編輯」設定學習單的內容，佇「預覽」看排版結果（電腦版是倒手爿編輯、正手爿預覽）。
          • 字的寸尺、底線樣式、逝距隨在你撨。
          • 揤「輸出 PDF」通輸出會當印出來練習的檔案。
          • 通匯入／匯出設定檔，共家己的學習單設定記起來，嘛通互相分享。
          • 「段落文字」適合寫較長篇的文字，嘛有支援 Markdown 語法；通過 ==文字== 標示螢光筆重點。
          • 「分頁標記」通指定系統佇佗位換後一頁。
          • 「自訂圖片」通貼網址，嘛通「對相簿揀圖」自動壓縮嵌入；設定內底若有填 Imgur Client ID，會嘗試上傳圖床了後代入網址。
          • 「模板」有預設的學習單版型，通直接載入使用抑是改內容。
          • 「建中的教材」有 建中的台語文入門課 的紙本教材，歡迎直接提去用抑是修改。
          • 「字詞見本」通佇仝一逝用「｜」抑是「|」分欄位：一個分兩欄、兩个分三欄
          • 通安裝到主畫面抑是電腦桌面，像 app 仝款開啟使用。

          安裝到主畫面

          iPhone／iPad 請用 Safari 開啟這个網頁，隨後：

          1. 揤底部分享鈕（方塊頂面一支箭）。
          2. 向下搝，選「加到主畫面」。
          3. 揤「加入」。了後就會當像 app 仝款開啟。

          電腦版 Chrome／Edge 通佇網址列正手爿的安裝圖示，抑是選單內底的「安裝應用程式」。
